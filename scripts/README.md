# Проверка и экспорт

```sh
python3 scripts/check.py
python3 scripts/check.py --output .audit-sim/submission
python3 scripts/check.py --archive .audit-sim/genesis-submission.zip
```

Единая команда запускает тесты, независимо проверяет конфигурации примеров и новый seed, отсутствующий в train/dev, дважды строит train/dev и их парные варианты, сравнивает байты и проверяет 20 пар в оценщике. Затем она оценивает четыре политики на каждом dev-эпизоде и записывает десять train-траекторий. При сбое команда возвращает ненулевой код. `--verbose` выводит подробности тестов, `--quick` пропускает только дополнительные примеры.

С `--output` сохраняются исходники, инструкции, 20 исходных эпизодов, 20 парных вариантов, метрики и `trajectories.jsonl`. Каталог должен быть пустым или ещё не существовать.

`--archive` записывает ZIP только после успешных проверок и добавляет список контрольных сумм. [Проверка комплекта и журналов](../docs/OPERATIONS.md)
