# Проверка и экспорт

```sh
python3 scripts/check.py
python3 scripts/check.py --output .audit-sim/submission
```

Единая команда запускает тесты, независимо проверяет конфигурации примеров, дважды строит train/dev и их парные варианты, сравнивает байты и проверяет 20 пар в оценщике. Затем она оценивает четыре политики на каждом dev-эпизоде и записывает десять train-траекторий. При сбое команда возвращает ненулевой код. `--verbose` выводит подробности тестов, `--quick` пропускает только дополнительные примеры.

С `--output` сохраняются исходники, инструкции, 20 исходных эпизодов, метрики и `trajectories.jsonl`. Каталог должен быть пустым или ещё не существовать. Парные варианты создаются во временном каталоге для проверки.
