# Алимжан — API среды, оценщик и политики агента

Готовый результат — автономная RL-среда, детерминированное сопоставление выводов, четыре политики, траектории и тесты. Алан отвечает за генератор, эпизоды, контейнер и комплект сдачи. Внешние API и обучение модели можно рассматривать после готовности обязательного офлайн-прогона. Такие интеграции и задачи по ИИ закреплены за Алимжаном. [План Алана](../alan/README.md)

- [x] **B09.** Валидировать схему `submit`. Проверять `episode_id` и обязательные поля `type`, `affected_ids`, `claimed_amount_minor`, `currency`, `evidence_ids` и `explanation`. - [x] **B10.** Нормализовать ID и проверить кандидатов на совпадение. Для TP требовать нужный тип, канонические затронутые ID, правильную валюту, сумму в явно заданном допуске и полный допустимый набор доступных доказательств. Утвердить допуски по типам с Аланом и покрыть тестом границы каждого допуска.
- [x] **B11.** Реализовать взаимно однозначное сопоставление с максимальным числом корректных пар и детерминированным выбором при равенстве. Дать тест с неоднозначными кандидатами. Несопоставленные и повторные выводы считать FP, пропущенные эталонные ошибки — FN. Опубликовать код нормализации и правила выбора.
- [x] **B12.** Рассчитать `P = TP/(TP+FP)`, `R = TP/(TP+FN)` и `F1 = 2TP/(2TP+FP+FN)`. При нулевом знаменателе P или R равны 0. При пустом ответе на чистых книгах F1 равна 1, при ложном обвинении на чистых — 0. Терминальная награда — `clip(2 * F1 - 1 - 0.002 * inspection_steps, -1, 1)`. Исследовательские шаги дают 0, поэтому возврат эпизода равен терминальной награде.
- [x] **B13.** Развести режимы. Открытый режим возвращает политике терминальную награду, закрытый удерживает награду и диагностику у оценщика до конца прогона. Проверить режимы на одном ответе и проверить отсутствие подсказок в промежуточных наблюдениях, ошибках и `info`.
- [x] **B14.** Запустить агента отдельно от оценщика, с доступом к данным через узкий интерфейс чтения и `submit`. Закрытые файлы и seed доступны только процессу оценщика или управляющему запускателю. Попросить Алана настроить контейнер в соответствии с этим разделением. Проверить доступность открытых данных и недоступность закрытых файлов, произвольного shell, SQL, файловых путей и сети через API.
