# Демо Genesis FinTech

## Запуск

Для показа сохранённого демо распакуйте ZIP и откройте `demo-report.html` в браузере. Терминал и интернет для этого не нужны.

Чтобы заново выполнить демо, на Linux из корня проекта запустите `python3 -m audit_sim demo`. С готовым образом те же два сценария можно запустить в контейнере без сети, в том числе через Docker Desktop на Mac.

```sh
docker run --rm --network none --cpus=2 --memory=4g genesis-audit python -m audit_sim demo
```

## Что показать за две минуты

1. **Задача.** «Мы построили воспроизводимую среду для оценки ИИ-аудитора. Она генерирует синтетические финансовые документы и проверяет, может ли агент подтвердить расхождения записями».
2. **Эпизод с ошибками.** Откройте в выводе `EP-CHK-A08` результаты `reconcile`. Сверка показывает дубль счёта и неполное распределение платежа. Для каждого вывода видны сумма, валюта, ID и сами открытые записи. Получилось 2 TP, 0 FP, 0 FN, F1 = 1 и награда 0,992.
3. **Чистый эпизод.** На `EP-QRS8HS6811` сверка возвращает пустой ответ и получает 0,984. Массовая пометка получает −1. Разницу между 1 и 0,984 даёт стоимость восьми запросов к записям.
4. **Воспроизводимость.** Покажите `validation.json` из архива. Там результаты четырёх политик на dev. Объём проверки включает 20 парных эпизодов с перестановкой строк и заменой ID. Политика работает через JSON-канал, а оценщик хранит эталон отдельно от наблюдений.

Для просмотра нового прогона в браузере запустите `python3 -m audit_sim demo --output .audit-sim/demo` и откройте `.audit-sim/demo/report.html`. На общем графике выберите награду и введите ID чистого эпизода, чтобы показать результаты по обе стороны от нуля. В карточке A08 переключите график расследования на «ID из ответа» и передвиньте ползунок на первые шаги. Полная проверка запускается через `python3 scripts/check.py`.

## Описание для формы сдачи

**MonkeyType — офлайн-симулятор финансового аудита для Genesis FinTech.** Генератор создаёт согласованную книгу и добавляет четыре настраиваемых типа расхождений, в том числе две комбинации ошибок. Агент через API исследует открытые записи и указывает доказательства. Изолированный оценщик проверяет выводы по типу, ID, сумме, валюте и полному набору доказательств. В архиве находятся исходники, контейнер, 10 train- и 10 dev-эпизодов, 20 вариантов для проверки воспроизводимости, тесты, четыре политики и траектории. Запуск работает на CPU без сети.
