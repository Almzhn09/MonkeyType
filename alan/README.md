# Алан — генератор данных, эпизоды и комплект сдачи

Готовый результат — генератор синтетических финансовых эпизодов, проверяемый эталон, 20 открытых эпизодов и контейнер с единой командой проверки. Алимжан отвечает за локальный API, оценщик и политики агента. [План Алимжана](../alimzhan/README.md)
